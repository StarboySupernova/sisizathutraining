LAB 03: Database Fault

Scenario: The syntax is fixed, but the app is failing during Database Boot. It is trying to query a table named `system_routes`, but that table doesn't exist in the SQLite database.

Phase 1 Governance & Tracking

Move task "Fix Database OperationalError" to In Progress on Kanboard.

Phase 2 Diagnostics & Repair

Run the application in the Mobile Terminal.
Observe the SQLITE ERROR.
Switch to the Code Editor tab. Fix the SQL query so it selects from network_routes instead of system_routes. Save & Run.

Phase 3 SLA & Knowledge Transfer

Log a Database Bug ticket at support.sisizathutraining.com.
Write a Wiki article at knowledgebase.sisizathutraining.com explaining SQLite Table names.
